### 1、Node.js的镜像源

下面的命令行可以查询当前Node.js使用的下载源。

```
npm get registry
```

npm的默认下载源是`https://registry.npmjs.org/`。在国内通常使用的是淘宝的镜像源`https://registry.npm.taobao.org`。输入下面的命令来修改镜像源：

```
npm config set registry https://registry.npm.taobao.org
```

修改完成后可以再次执行`npm get registry`来查看下载源是否修改完成。
