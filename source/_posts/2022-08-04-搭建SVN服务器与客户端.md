搭建SVN服务器与客户端

服务器使用VisualSVN，而客户端使用TortoiseSVN。

首先，需要有一台主机安装VisualSVN，这台主机将作为服务器，为下游客户端提供版本控制服务。而下游的客户端需要安装TortoiseSVN来使用服务器提供的服务。

* * *

## 服务器

### 服务器安装

下面是VisualSVN的官网。

[Subversion Server for Windows | VisualSVN Server](https://www.visualsvn.com/server/)

你可以在这里先查看VisualSVN不同版本的价格和对应的功能。当然也可以只使用免费的社区版。

[Pricing | VisualSVN Server](https://www.visualsvn.com/server/licensing/)

下面是VisualSVN官网的下载地址。可以自行选择需要的版本。

[Download | VisualSVN Server](https://www.visualsvn.com/server/download/)

你可以在下面的链接中找到官方的安装流程。在安装过程中可能会出现Select the authentication mode，也就是选择身份验证模式。如果选择Use Windows authentication则需要提供许可证密钥。在安装时需要注意。

[Getting Started | VisualSVN Server](https://www.visualsvn.com/server/getting-started/)

### 服务器配置

在VisualSVN安装完成之后，我们需要先配置服务器的网络环境。之后创建供客户端使用的存储库。

配置服务器的网络环境可以参考下面的文章。

[SVN服务器远程访问 - 简书 (jianshu.com)](https://www.jianshu.com/p/ba1246dac10d)

存储库的搭建可以参考下面的文章。

[搭建SVN服务器详细教程](https://blog.csdn.net/daobantutu/article/details/60467185)

如果使用Windows身份验证模式，可以在安装后，查看官网的这篇文章进行配置。

[How to configure Integrated Windows Authentication in VisualSVN Server | VisualSVN Help Center](https://www.visualsvn.com/support/topic/00043/)

* * *

## 客户端

下面是TortoiseSVN的官网。

[Home · TortoiseSVN](https://tortoisesvn.net/)

下面是TortoiseSVN的下载地址。可以自行选择需要的版本。

[Downloads · TortoiseSVN](https://tortoisesvn.net/downloads.html)

安装的TortoiseSVN默认是英文的，如果需要中文，可以在下面的网址选择对应版本的汉化包进行安装。

[Downloading File / - TortoiseSVN - OSDN](https://osdn.net/projects/tortoisesvn/storage/)

对汉化流程不熟悉的可以查看下面的文章。

[解决SVN安装语言包后无法选择中文的问题。](https://blog.csdn.net/qq_39355295/article/details/88981409)

在客户端中安装TortoiseSVN完成后，可以直接使用存储库的URL进行访问。
