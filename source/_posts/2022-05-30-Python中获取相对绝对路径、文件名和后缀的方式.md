## ##Python中获取相对/绝对路径、文件名和后缀的方式。

先假定一个文件绝对路径：

```
file_path = r'E:\GitHubLibrary\blog'
```

在Python中与路径，文件和文件夹相关的操作都离不开os包。

```
import os

parent_path = os.path.dirname(file_path)

os.path.abspath(path)
```
