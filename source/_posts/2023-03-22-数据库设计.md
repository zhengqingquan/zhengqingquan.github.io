### 先说下数据库常用的数据类型

MySQL主要分为三类数据类型：字符、数字和日期。

| 类型 | 说明 |
| --- | --- |
| CHAR(_size_) | 保存固定长度的字符串（可包含字母、数字以及特殊字符）。在括号中指定字符串的长度。最多 255 个字符。 |
| VARCHAR(_size_) | 保存可变长度的字符串（可包含字母、数字以及特殊字符）。在括号中指定字符串的最大长度。最多 255 个字符。   注释：如果值的长度大于 255，则被转换为 TEXT 类型。 |
| TINYTEXT | 存放最大长度为 255 个字符的字符串。 |
| TEXT | 存放最大长度为 65,535 个字符的字符串。 |
|  |  |

| 类型 | 说明 |
| --- | --- |
| DATE | 日期。主要用来描述年月日的日期，不包含小时制。   格式：YYYY-MM-DD   注释：支持的范围是从 '1000-01-01' 到 '9999-12-31' |
| DATETIME() | 日期和时间的组合。   格式：YYYY-MM-DD HH:MM:SS   其中()中的值为秒的精度，DATETIME(3)表示精确到毫秒   注释：支持的范围是从 '1000-01-01 00:00:00' 到 '9999-12-31 23:59:59' |
| TIMESTAMP() | 时间戳。TIMESTAMP 值使用 Unix 纪元('1970-01-01 00:00:00' UTC) 至今的描述来存储。格式：YYYY-MM-DD HH:MM:SS   注释：支持的范围是从 '1970-01-01 00:00:01' UTC 到 '2038-01-09 03:14:07' UTC |
| TIME() | 时间。主要用来描述小时制的时间，不包含年月日。   格式：HH:MM:SS   注释：支持的范围是从 '-838:59:59' 到 '838:59:59' |
| YEAR() | 2 位或 4 位格式的年。   在MySQL中默认以4位数字的格式存储。从 MySQL 5.7.6 版本开始，YEAR 类型的默认行为发生了变化，变成只存储 2 个数字。如果插入的 YEAR 值是 2 个数字，则将其解释为 1970 年至 2069 年之间的年份。   注释：4 位格式所允许的值：1901 到 2155。2 位格式所允许的值：70 到 69，表示从 1970 到 2069。 |
