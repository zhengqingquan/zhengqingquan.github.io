大多数周刊可能都需要英文阅读能力。而且是邮件订阅的。

### 综合平台

[稀土掘金 (juejin.cn)](https://juejin.cn/)：国内目前用得比较多的综合平台，全栈信息应有尽有。

[InfoQ](https://www.infoq.cn/) ：包括新闻资讯、技术文章等。

[CodeProject - For those who code](https://www.codeproject.com/)：一个以各种应用技术为主的综合网站，包括了各个方向的内容。

### 开源周刊

[ruanyf/weekly: 科技爱好者周刊，每周五发布 (github.com)](https://github.com/ruanyf/weekly)：开源周刊，主要是一些咨询，还有些开源项目推荐。

[521xueweihan/HelloGitHub: 分享 GitHub 上有趣、入门级的开源项目。](https://github.com/521xueweihan/HelloGitHub)：分享一些开源项目，缺点是更新很慢，三周一更。开源项目分布各种语言和应用。还会推荐一些开源书籍。

### 后端周刊

[Baeldung](https://www.baeldung.com/)：Baeldung 发布的一周一次的 Java 技术周刊，包括 Java、Spring、REST、JavaScript、Security 和其他相关技术的最新文章和教程。

[Java Specialists](https://www.javaspecialists.eu/)：这周刊比较高端，通常用于解决Java性能问题。由 Java 专家团队发布的 Java 周刊，深入探讨 Java 语言和平台的高级主题。

[Java Performance Tuning](http://javaperformancetuning.com/)：由 Java 性能专家发布的 Java 性能调优周刊，提供最新的 Java 性能调优技巧、工具和最佳实践。

[Oracle Blogs | Java Magazine](https://blogs.oracle.com/javamagazine/)：由 Oracle 发布的 Java 杂志，提供 Java 平台、语言和工具的最新信息、趋势、案例研究和专家观点。

[Java - Resources and Tools - IBM Developer - IBM Developer](https://developer.ibm.com/languages/java/)：全球规模最大、访问量最高的企业级开发社区

### 前端周刊

[Frontend Focus](https://frontendfoc.us/)：每周一次的优质前端新闻、文章和教程导航。 HTML、CSS、WebGL、Canvas、浏览器技术等。

[JavaScript Weekly： The JavaScript Email Newsletter](https://javascriptweekly.com/)：和Frontend Focus一样的前端资讯订阅网站。以JS和前端框架为主。

[The CodePen Spark](https://codepen.io/spark)：一个以前端为主的教学网站，展示很多漂亮的前端效果。

[奇舞周刊 (75.team)](https://weekly.75.team/)：一个也是以前端为主的咨询网站，里面也有一些推荐与实践的内容。更新稳定，通常一周一更。
