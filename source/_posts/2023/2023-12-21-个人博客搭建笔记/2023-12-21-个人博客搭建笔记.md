# 个人博客

1. 目标是hexo框架。
2. 使用NexT主题。风格参考了：https://mrbird.cc/
3. 需要有后台，可以统计数据。hexo admin
4. 界面的个性化设置。

## 环境

```
node.js
git
```

## 安装

```
npm install -g hexo-cli
```

## 建立

首先需要了解github为什么能搭建博客。
我创建的仓库是`https://github.com/zhengqingquan/zhengqingquan.github.io`为什么我可以通过`https://zhengqingquan.github.io/`去访问主页？

这个是因为Github page的机制，

[pages.github](https://pages.github.com/)
[GitHub Pages 文档](https://docs.github.com/zh/pages/getting-started-with-github-pages)

首先需要了解

----
部署 userName.github.io 命名的仓库

github会自动给构建这个仓库下面的内容到`https://userName.github.io/`

域名下，”/“ 后面就是你仓库内文件的根路径，具体页面根据仓库内文件结构添加即可访问。
例如：仓库里根路径下有一个test.html
就可以访问：https://userName.github.io/test.html

https://javabullshit.github.io/posts/set-docs-folder-as-root-dir/
