# 个人博客

## 基础

🌐 **Website**: [https://zhengqingquan.github.io](https://zhengqingquan.github.io)

采用 `Hexo` 博客框架，搭配 `NexT` 主题（目录 `themes/next`，由原 Scallop 重命名）。

使用 `subtree` 的方式内嵌博客主题代码库。

使用 `Github actions` 部署。

## 环境

```
Git
Node.js v22.17.0
```

## Node 包依赖

```
hexo v7.3.0
```

## 使用方法

```bash
npm install

hexo g

hexo s
```
